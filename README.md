# Diplom_3
Автоматизация UI-тестов веб-приложения Stellar Burgers.

Проект реализован с использованием паттерна Page Object и покрывает ключевые пользовательские сценарии: регистрацию, авторизацию и работу с конструктором бургеров.

## Используемые технологии

* Java 11
* Selenium WebDriver
* JUnit 4
* Maven
* Allure Report
* WebDriverManager

## Архитектура проекта

Проект построен с использованием паттерна Page Object Model (POM).

### Структура проекта

* pages — Page Object классы
* tests — UI-тесты
* utils — базовые настройки, генерация данных и конфигурация браузеров

## Реализованные проверки

### Регистрация

Проверены сценарии:

* успешная регистрация пользователя;
* отображение ошибки при некорректном пароле.

### Авторизация

Проверен вход:

* через кнопку «Войти в аккаунт»;
* через кнопку «Личный кабинет»;
* через форму регистрации;
* через форму восстановления пароля.

### Конструктор

Проверены переходы между разделами:

* Булки;
* Соусы;
* Начинки.

## Поддерживаемые браузеры

* Google Chrome
* Yandex Browser

## Запуск тестов

### Google Chrome

mvn clean test

### Yandex Browser

mvn clean test -Dbrowser=yandex

## Генерация Allure-отчета

mvn allure:serve
